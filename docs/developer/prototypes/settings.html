# Review the jobs to review

Use this workflow to review, classify and clear the queue of new jobs, as
routine work under the operating mandate. A run the owner asked only to
inspect is read-only. Triage does not prepare applications, change
application stages or change collection.

## Open a run

Open a run named review-inbox with the jobs in scope. Every change you make
is attached to it. Close it with a report: changes, not done, checks, limits.

## Decide from the current policy

Read the Decision and Eligibility sections of the policy. They own the
criteria. Explain the fit or mismatch with specific facts, not a keyword
score. Missing evidence does not establish that a skill is absent.

Shortlist or dismiss only when the evidence supports the decision. If a
plausible role depends on a fact the policy does not state, leave the job,
ask the owner one question about it, and continue with the other jobs.
